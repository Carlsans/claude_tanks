# Claude Tanks

Two identical tanks duel in a random arena (open field → light labyrinth), each driven by a black-box neural network. The app trains networks with neuroevolution (GA, NEAT) and reinforcement learning (PPO), compares architectures, and replays battles in real or accelerated time. Everything runs on CPU; the GUI is a light 2D egui (OpenGL) window.

Platforms: Linux and Windows.

```
cargo run --release
```
